# FORM — Move well. Live fully.
An English-language personal training landing page. Editorial design, warm paper tones, cobalt blue, sage green, and interactive coaching programs.

No dependencies or build step. Open dist/index.html or serve dist through an HTTP server.

Files:
- dist/index.html — content and layout
- dist/style.css — responsive styling
- dist/app.js — accessible program tabs, navigation, and a local introduction form

Customize the brand, trainer biography, credentials, service locations, and real contact channel before accepting enquiries. All images are illustrative Unsplash photography. No testimonials, trainer qualifications, prices, or results have been invented. The form generates a copyable introduction locally; nothing is submitted or stored.
